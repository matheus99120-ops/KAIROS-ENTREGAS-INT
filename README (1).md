1. Acesse **github.com/new** → nome: `kairos-fretes` → **Public** → **Create repository**
2. Clique **"uploading an existing file"** → envie `index.html` e `README.md` → **Commit changes**
3. Vá em **Settings → Pages** → Source: `main` / `/(root)` → **Save**
4. Aguarde ~1 min → site em: `https://SEU_USUARIO.github.io/kairos-fretes`
